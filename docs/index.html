Features

Everything you need for quiz night

Built to run on a Raspberry Pi or a cloud VM — no third-party service required.

📷

QR-code join

Players scan a QR code or type a short code — no app download, no account.

📚

Scripture on every reveal

KJV, WEB, and ASV verse text displayed after each answer. The teaching moment is the point.

🏠

Runs on a Raspberry Pi

One-line installer sets up Docker, clones the repo, and starts the stack on a Pi in minutes.

🔒

Privacy-first

Nicknames only. No email, no accounts, no device fingerprinting. IPs are HMAC-hashed before storage.

⚡

Real-time, no polling

Socket.IO keeps the host screen and every player in sync. Sessions survive server restarts.

🌐

No inbound ports needed

Reference deployment uses a Cloudflare Tunnel — your server never exposes a public port.

Quick Start

Up and running on a Raspberry Pi

The one-line installer handles everything: Docker, secrets, Bible texts, and the full stack.

1

Run the installer

Run this on a fresh Raspberry Pi (or any Debian/Ubuntu host) as root or with sudo.

curl -fsSL https://raw.githubusercontent.com/darqlab/scripturejam/main/scripts/install.sh | sudo bash
2

Install Bible texts (optional, recommended)

The installer prompts you to download KJV, WEB, and ASV from public-domain sources (~17 MB). Alternatively run manually:

bash content-tools/scripts/install-bible-texts.sh
3

Open the host console

Navigate to the host dashboard on any device on the same network and create your first session.

http://<pi-ip>:4000/host
4

Players join

Share the QR code shown on the host screen, or have players visit the join URL directly.

http://<pi-ip>:4000/j/<code>
Deployment

Two paths to production

Choose the option that fits your infrastructure. Both use Docker Compose.

Recommended

Cloudflare Tunnel

No inbound ports. Your server stays behind a firewall; Cloudflare proxies traffic through an outbound tunnel.

Read the guide →
Alternative

Caddy + Let's Encrypt

Static IP or port-forward required. Caddy handles automatic TLS certificate issuance and renewal.
